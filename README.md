# TikTzuki Scripts

## CLi tools

Tools

- env-mapper: A tool to map environment variables into frontend applications at runtime.
- cargo-template: A tool to generate files from templates using Cargo-like syntax.

Install
```shell
curl -s https://raw.githubusercontent.com/TikTzuki/tiktuzki-scripts/refs/heads/master/install.sh | \
bash -s -- --tool <tool-name>
```
